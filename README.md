# 👠 Vênus Shoes

Esse é um projeto autônomo que iniciei para estudar Front-end. Se trata de uma leanding page de uma loja online fictícia.
Comecei esse projeto para trabalhar com a criação de uma experiência visual agradável para apresentar produtos, destacar coleções e facilitar a navegação dos usuários. O objetivo era por em prática minhas habilidades em HTM, CSS e um pouco de JavaScript enquanto estudo Front-end.

## 🚧 Status

O projeto ainda está em desenvolvimento. Eu pretendo criar novas funcionalidades ao longo do tempo.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## 🎯 Objetivos

- Praticar a estruturação de páginas com HTML.
- Desenvolver layouts e estilos utilizando CSS.
- Implementar interatividade com JavaScript.
- Aprimorar conhecimentos em desenvolvimento front-end.
